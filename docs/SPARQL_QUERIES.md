# SPARQL queries

- Sources supérieures à 500 kW: liste les installations de production au-dessus de 500 kW.
- Bâtiments industriels: filtrage par classe `Industriel`.
- Plus gros consommateur: tri par consommation annuelle.
- Gestionnaire des lignes: relation `gerePar`.
- Éoliennes: sélection par classe.
- Autres requêtes: moyenne, somme, ask, long lines, etc.

Les requêtes sont stockées dans le catalogue via `backend/app/ontology_store.py`.
